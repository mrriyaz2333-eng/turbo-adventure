ADMIN PANEL APK PROJECT

This is a clean Android WebView wrapper for:
https://mrriyaz2333-eng.github.io/Admin-panel/index.html

It is designed to be built remotely with GitHub Actions, so the phone does not need Android Studio.

Important: upload the project files/folders to the ROOT of your GitHub repository.
The .github/workflows/build-apk.yml file is included for automatic APK builds.
